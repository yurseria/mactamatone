# Theme background artwork

Generated with the built-in image_gen tool. These opaque, scenery-only images are independent of all instrument cutouts and mouth frames. The app loads them behind the instrument in the settings preview; the classic theme keeps its original studio background.

Final assets:

- `Sources/Mactamatone/Resources/OtamatonePinkBackground.png`
- `Sources/Mactamatone/Resources/OtamatoneCatBackground.png`
- `Sources/Mactamatone/Resources/OtamatoneChickBackground.png`
- `Sources/Mactamatone/Resources/OtamatoneGalaxyBackground.png`
- `Sources/Mactamatone/Resources/OtamatoneShibaBackground.png`

## Display tuning

After inspecting full-strength backgrounds in the actual settings layout, the app reduces background saturation to 0.65 and blends each image over its theme color. Pink, Cat and Shiba use opacity 0.50, Chick 0.56, and Galaxy 0.44. This keeps the scene visible while preserving the contrast of the untouched foreground instrument. The soft floor shadow is a separate layer.
